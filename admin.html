Вход

Вставьте ключ доступа один раз — телефон его запомнит.

Где взять ключ?
  1. Зайдите на github.com → новый ключ под аккаунтом, где лежит сайт.
  2. Token name — например «Вэри Cozy». Expiration — 1 год.
  3. Repository access → Only select repositories → выберите Testleska.
  4. Permissions → Repository permissions → Contents → Read and write. Больше ничего не включайте.
  5. Нажмите Generate token, скопируйте ключ (начинается с github_pat_) и вставьте его сюда.

Такой ключ может менять только этот сайт. Если он потерялся или устарел — удалите его там же и сделайте новый.
