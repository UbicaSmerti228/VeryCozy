# Вэри Cozy

Сайт керамических кружек ручной работы Леси (Иркутск).

Статический сайт без сборки: `index.html`, `style.css`, `script.js`, список кружек `products.json` и картинки в `assets/`.
Публикация: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.

## Как добавить новую кружку

Всё делается прямо на сайте GitHub, с телефона тоже можно.

**1. Загрузить фото.**
Откройте папку `photos` → **Add file → Upload files** → выберите фото → **Commit changes**.
Лучше вертикальные фото, как у кружки с пирсингом. Имя файла — латиницей без пробелов, например `mug-angel-1.jpg`.

**2. Добавить кружку в список.**
Откройте файл `products.json` → карандаш ✏️ (Edit) → после закрывающей `}` последней кружки поставьте запятую и вставьте новый блок:

```json
  {
    "название": "Кружка с ангелом",
    "цена": 2800,
    "описание": ["керамика", "350 мл", "ручная работа"],
    "фото": [
      { "файл": "photos/mug-angel-1.jpg", "подпись": "Кружка с ангелом, вид сбоку" },
      { "файл": "photos/mug-angel-2.jpg", "подпись": "Кружка с ангелом, вид сверху" }
    ],
    "продана": false
  }
```

Нажмите **Commit changes**. Через 1–2 минуты кружка появится на сайте.

- **название** — так кружка называется на сайте и в сообщении «Хочу «…» за … ₽», которое уже вписано в кнопку.
- **цена** — просто число, без пробелов и «₽».
- **описание** — короткие слова через запятую, на сайте они идут через золотые точки.
- **фото** — сколько угодно; если фото одно, переключателя под ним не будет.
- **продана** — поставьте `true`, когда кружку купили: вместо цены будет «продана», а кнопка станет «Хочу похожую».

Чтобы убрать кружку — удалите её блок целиком (вместе с запятой перед ним).

Главное: кавычки `"`, запятые между блоками и скобки `[ ]` `{ }` должны остаться на месте. Если после сохранения кружки пропали — скорее всего, потерялась запятая или кавычка; сайт тогда покажет только первую кружку и не сломается.
